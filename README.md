# 🚀 Professional Space Mission Analytics Dashboard

A professional **Space Mission Analytics Dashboard** built using **Python, Pandas, and Matplotlib**. This dashboard analyzes mission performance, launch statistics, satellite deployments, mission budgets, astronaut participation, and success rates through KPI cards and interactive visualizations.

---

## 📊 Dashboard Features

- 🚀 Total Missions KPI
- ✅ Successful Missions KPI
- ❌ Failed Missions KPI
- 🛰️ Satellites Launched KPI
- 💰 Mission Budget Analysis
- 👨‍🚀 Astronaut Missions
- 📈 Monthly Mission Trend
- 📊 Success vs Failure Analysis
- 🌍 Country-wise Mission Analysis
- 🌕 Mission Destination Distribution
- 📈 Mission Success Rate
- 📊 Budget vs Missions Comparison
- 🌙 Professional Dark Theme

---
